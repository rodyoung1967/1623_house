# Source register

IDs are stable. New sources get the next number in the same prefix. Machine mirror: `data/sources.yaml`.

**Prefixes:**

| Prefix | Meaning |
| --- | --- |
| `P` | Primary municipal, census, or property record |
| `O` | Oral history |
| `W` | Published / web sources (newspapers, directories, indexes, guides). A clipping can still be primary evidence for what it says. |
| `S` | Compiled notes already in this archive |
| `M` | Maps and aerials |
| `PL` | Plans |
