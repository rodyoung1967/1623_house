# Research workspace

This directory holds **project-created research material**, not original source files.

- `notes/` — transcriptions, follow-up research, search methods, and source-reading notes.
- `audits/` — repository/data-consistency reviews.

Original documents, screenshots, newspaper captures, census saves, plans, and other evidence belong under `sources/ingested/`. Derived text/images extracted from compiled documents belong under `sources/extracted/`.

Accepted claims should be promoted from research notes into the root narrative/register files (`house-history.md`, `timeline.md`, `people.md`, `sources.md`, `decisions.md` / `CONFLICTS.md`) and the matching YAML mirrors in `data/`.
